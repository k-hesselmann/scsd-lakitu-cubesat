\section{Preliminary Budgets}

The following power, mass, link, and data budgets represent the -- now outdated -- preliminary design state of the mission. Blue-coded values in the underlying spreadsheets are taken directly from datasheets; yellow-coded values are engineering assumptions with explanations given alongside each figure; green-coded cells indicate a cited source. All figures are subject to change as hardware is measured, tested, and finalised in later project phases.
